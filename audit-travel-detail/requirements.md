# 教育局端出行申报——课程与出行方案需求说明

## 1. 需求概述

在教育局端“活动明细”页中，将“接待方案与课程”区域改为两个可直接查看详情的列表：

1. 出行方案列表；
2. 研学课程列表。

两个列表位于“活动基础信息”和“活动人员信息”之间。列表不再提供勾选框和状态列，每行只保留“详情”“PDF下载”两个操作。一个出行申报只关联一个出行方案，因此出行方案列表固定展示一条数据。

## 2. 页面与交互路径

| 序号 | 页面/区域 | 用户操作 | 结果 |
| --- | --- | --- | --- |
| 1 | 活动明细 | 查看“接待方案与课程” | 展示“出行方案”和“研学课程”两个列表 |
| 2 | 出行方案列表 | 点击“详情” | 跳转到基地端“学校活动详情”页面 |
| 3 | 出行方案列表 | 点击“PDF下载” | 进入“学校活动详情”并调起打印，生成该出行方案 PDF |
| 4 | 研学课程列表 | 点击“详情” | 跳转到基地端“课程详情”页面 |
| 5 | 研学课程列表 | 点击“PDF下载” | 进入“课程详情”并调起打印，生成该课程 PDF |
| 6 | 学校活动详情/课程详情 | 点击“返回活动明细” | 返回教育局端“活动明细”页 |
| 7 | 学校活动详情/课程详情 | 点击“PDF下载” | 仅打印当前详情内容，不打印导航、标签栏和列表 |

详情页采用页面跳转方式，不使用弹窗。URL 通过 hash 区分：

- 出行方案详情：`#plan-detail`
- 课程详情：`#course-detail`

浏览器后退按钮可返回活动明细。

## 3. 列表规格

### 3.1 出行方案列表

列表标题：`出行方案`

字段顺序：

| 字段 | 说明 |
| --- | --- |
| 活动名称 | 出行方案名称 |
| 适合学段 | 方案适用学段 |
| 活动时长(天) | 数字，保留 1 位小数 |
| 活动类型 | 研学活动分类 |
| 接待主体 | 基地名称，前置“基地”标签 |
| 创建账号 | 创建方案的基地管理员账号 |
| 创建时间 | `YYYY-MM-DD HH:mm:ss` |
| 操作 | 仅“详情”“PDF下载” |

示例数据：测试方案 / 小学一二年级 / 1.0 / 优秀传统文化 / 贵州省桥梁科普教育博物馆 / 贵州省桥梁科普教育博物馆管理员 / 2026-11-09 15:24:40。

列表标题：`研学课程`

字段顺序：

| 字段 | 说明 |
| --- | --- |
| 课程名称 | 课程全称，超长省略并保留 title |
| 适合学段 | 课程适用学段 |
| 课程时长(小时) | 数字 |
| 课程类型 | 课程分类标签 |
| 创建账号 | 创建课程的基地管理员账号 |
| 创建时间 | `YYYY-MM-DD HH:mm:ss` |
| 操作 | 仅“详情”“PDF下载” |

- 真实职场体验测试 / 高中 / 10 / 国情市情教育；
- 观音洞探秘 / 初中 / 4 / 国防科工教育；

### 3.3 列表通用规则

- 不展示勾选框、全选按钮和批量操作栏。
- 不展示“状态”列。
- 行高按内容自适应，长课程名称和长学段允许换行。
- 操作列固定为“详情”“PDF下载”，不出现“下架”“上架”“小程序端预览”等其他操作。
- 两个列表之间用虚线分隔，不使用弹窗承载详情。

## 6. PDF 下载规则

- PDF 使用浏览器打印能力生成，纸张为 A4 纵向。
- 打印内容只包含当前详情页的正文卡片。
- 不打印左侧导航、顶部栏、页面标签、返回按钮和“PDF下载”按钮。
- 图片按比例缩放，卡片尽量避免跨页截断。
- 出行方案和课程分别生成对应 PDF，不混合打印。

## 7. 静态演示说明

- 演示文件：`audit-travel-active-detail.html`。

- 课程视频使用占位播放器，不下载远程视频文件。
